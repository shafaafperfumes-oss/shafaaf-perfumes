## The website (plain HTML/CSS/JS, Cloudflare; API on Railway; DB Supabase)
Public pages: `/` (index.html), `/shop` (shop.html, `?type=perfume|attar|bakhoor`),
`/product?id=<slug>` (product.html), `/about`, `/contact`, `/fragrance-finder`.
Private (noindex): cart, checkout, orders, wishlist, admin.
`/sitemap.xml` and `/robots.txt` are generated by `worker.js`.
Product data lives in the database; `js/data/products.js` is the seed copy.
Weekly numbers: `.claude/team/data/<YYYY-MM-DD>-analytics.json`, exported by the owner's
backend (`npm run analytics:export`) — counts and rupee totals only, no customer details.
The Analytics agent reads that file and nothing else; no agent has database access.

## Rules that bind every agent
1. **Never change a product's name, price or notes.** Descriptions are editorial and
   may be improved, but only as a proposal until the owner says yes.
2. **Nothing goes live, gets posted, published or sent without the owner's explicit
   approval.** Agents produce drafts and reports; a human (or Claude Code after a
   "HAAN") ships them.
3. **No secrets.** Never ask for, print, store or paste passwords, API keys or tokens.
   Never read `backend/.env`.
4. **Truth over hype.** No made-up statistics, reviews, awards or claims. If a
   number is an estimate, label it as one.
5. **Write for the owner:** every report ends with a short summary in simple
   Hinglish (Roman script) — what was done, what he must decide, what's next.
6. Report files go in `.claude/team/reports/<YYYY-MM-DD>-<agent>.md`. Do not
   commit; the leader/Claude Code commits after the owner has seen the work.
